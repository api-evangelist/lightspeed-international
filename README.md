# Lightspeed International

Lightspeed International Inc. was a software company founded in 1995 that developed voice control
software for data communications networks — an early entrant in the mid-1990s effort to carry voice
traffic over packet-switched data infrastructure. Co-founded and led by CEO Lev Volftsun, it was
backed at the early stage by Lightspeed Venture Partners and acquired by Cisco Systems, Inc. in 1997.

The company has not operated independently since that acquisition. It predates the public web API era
and never published an API, developer portal, SDK, or machine-readable interface, so this repository
carries no artifacts. It is retained as a historical record of the Lightspeed Venture Partners
portfolio.

**Status:** acquired (Cisco Systems, Inc., 1997) — historical, no API surface

## Not to be confused with

- **Lightspeed Commerce** (lightspeedhq.com) — retail/restaurant POS platform and an active API
  provider, profiled in this network at `all/lightspeed` and `all/lightspeed-pos`.
- **Lightspeed Financial / Lightspeed Trading** (lightspeed.com) — active-trading platform.
- **Lightspeed Venture Partners** (lsvp.com) — the investor. The shared name is coincidental;
  Lightspeed International was a portfolio company, not an affiliate.
